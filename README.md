# Enunciado
Organizem-se em grupos de 3 ou 4 integrantes para desenvolver uma aplicação que simule processos percorrendo um labirinto.

Antes de iniciar a atividade, consultem novamente o slide “O Labirinto dos Processos”, localizado ao final da Aula 03, pois ele apresenta as orientações e sugestões para o desenvolvimento da solução.



A aplicação poderá ser desenvolvida utilizando chamadas de sistema como fork() e exec(), em C/Linux, ou recursos como multiprocessing, em Python. O programa deverá:

criar múltiplos processos, cada um responsável por executar determinadas tarefas;

representar visualmente o labirinto, utilizando caracteres no terminal, interface gráfica simples ou outra solução criativa;

mostrar os processos percorrendo diferentes caminhos ou etapas do labirinto;

permitir criar, finalizar, suspender e retomar processos durante a execução;

utilizar pelo menos uma forma de comunicação ou sincronização entre os processos, como pipes, semáforos ou mecanismo equivalente;

permitir que um processo encontre a saída do labirinto somente depois de cumprir todas as tarefas ou etapas que lhe foram atribuídas.
